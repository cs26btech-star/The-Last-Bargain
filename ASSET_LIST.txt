THE LAST BARGAIN - EVERY PICTURE THE GAME USES (one file per spot)
======================================================================

How it works: each spot in the game has its OWN file in the art/ folder. To replace one,
save your drawing over the file with the exact same name (transparent PNG, any size).
If a file is missing, the game shows a coloured box or a placeholder, so it never crashes.
Right now every file is a COPY of the old sheet art, so the game looks the same until you replace them.

WHAT WAS SHARED BEFORE (and is now split):
  body_idle         -> your character AND the Pickpocket boss (2 places)
  weapon_sword/spear/dagger -> in your hand AND all 8 weapon tiles in both shops (9 places each)
  icon_potion       -> 6 different items (3 demon potions + 3 angel contracts)
  icon_gavel        -> 2 items (Holy Judgement + Devil's Judgement)
  beacon_demon      -> the shrine AND the panel beside it (2 places)
  shopkeeper_angel  -> angel shop window, Archangel story card, arena angel panel (3 places)
  boss_storekeeper  -> demon shop window AND the catalogue window (2 places; the boss itself is drawn by code)
  ui_panel          -> demon shop, angel shop and catalogue windows (3 places)
  ui_button         -> 8 different groups of buttons
  ui_hpbar          -> your health bar AND the enemy health bar (2 places)
  coin              -> not used anywhere yet
